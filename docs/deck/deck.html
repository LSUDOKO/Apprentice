02 · the insight
why this only works on agent-native

A click and an agent call are the same typed action.

In Agent-Native, the UI and the agent share one set of actions. So every triage click is already a structured demonstration: action name, typed arguments, the issue it touched. No screen scraping, no guessing.

// actions/label-issue.ts export default defineAction({ schema: z.object({ issueId, add, remove, playbookContext, }), ...domainAction("label-issue", …), });

03 · how it works
the loop

Watch. Prove. Then act.

1 watch

Typed clicks become demonstrations

Every action Maya takes is recorded with its arguments and the issue's features.

2 notice

Two similar ones become a pattern

A ghost chip predicts the next step. A pattern card proposes a playbook.

3 prove

Backtest, shadow, tests

Replay on history, review in shadow mode, and every correction becomes a regression test.

4 earn

Autonomy on a trust ladder

Watch → Suggest → Draft → Act → Auto, gated by the framework's approval hook. Undo any run.
